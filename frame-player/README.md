# Frame Studio

A static, responsive frame-by-frame video viewer.

## Features

- Load a browser-accessible HTTPS video URL or a local video file.
- Step backward or forward using the selected FPS estimate.
- Play through the normal browser media pipeline while presenting decoded frames on canvas.
- Scrub, change playback speed, mute, and enter fullscreen.
- Keyboard shortcuts for frame stepping and five-second skips.

## Limitations

GitHub Pages cannot resolve YouTube, Bilibili, or other watch-page URLs into media streams. Remote sources must be direct media URLs that the browser can load. Codec, CORS, authentication, range-request, and mixed-content restrictions still apply.

Use only while parked or by a passenger. This project does not override vehicle or browser playback safety controls.
